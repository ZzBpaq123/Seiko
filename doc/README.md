# Seiko Work 功能需求

下表按讨论顺序列出 Seiko Work 的功能需求和讨论结论。

| 项目 | 讨论结果 |
| --- | --- |
| [01 首页日程与待办亮点](01-home-schedule-and-tasks.md) | 首页提供两个独立亮点，按各自的数据决定是否显示。待办弹框支持勾选完成、快速新增和进入 `#tasks`。 |
| [02 邮件转待办](02-mail-to-task.md) | 从邮件详情创建待办，并在待办详情保留「查看原邮件」。 |
| 03 发薪周期分类预算 | 暂缓。 |
| [04 日程到期提醒](04-event-reminders.md) | 支持站内、邮件和微信服务号。微信接入前需要核验目标服务号的通知权限和可用模板。重复日程留作后续讨论。 |
| [05 账单导入与导出](05-bill-import-export.md) | 两个方向都纳入需求。首版建议使用可往返的 Seiko CSV，外部账单来源待定。 |
| [06 每日工作记录与周报交接](06-work-log-weekly-report.md) | 每天集中收集工作进展，按周生成可编辑的周报草稿，按项目汇总交接材料。 |
| 07 工作决策记录 | 暂缓。 |
| [08 工作知识库](08-work-knowledge-base.md) | 独立模块，按天收集对话、截图、文件和链接，支持日期、标签和关键词检索，可关联项目。 |

邮件转待办沿用首页待办功能提供的任务入口。账单导入与导出可以独立推进。
