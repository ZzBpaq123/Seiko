# 每日工作记录与周报交接

每天集中收集工作进展。写周报或交接时，直接从已经保存的每日记录提取材料，再编辑成稿。

## 每日收集

- 打开「每日工作记录」，默认查看当天，可切换日期补写或查看历史。
- 首版建议自动列出当天完成的待办。用户可以选哪些放入当日记录，并补充当天做了什么、目前卡在哪里、下一步是什么。
- 一天可以记录多个项目的进展，也可以直接补记临时处理的事项。每条记录可附相关任务、文档链接或其他资料入口。
- 保存后按日期和项目查看，也可以回来补充或修订。

## 生成周报与交接

| 场景 | 操作和内容 |
| --- | --- |
| 写周报 | 选一周或自定义日期范围，按项目汇总本周完成、仍在推进的关键进展和下周计划。 |
| 做交接 | 选择项目，汇总其最近进展、当前卡点、下一步和相关资料。 |

生成的草稿可以编辑和复制。汇总内容来自已保存的工作记录和选中的待办，用户可打开来源核对。

## 实现衔接

- 待办标记完成时记录实际完成时间，供每日收集使用。已有任务可以通过每日记录手动补记历史进展。
- 每日记录按用户工作日期保存，并可关联多个事项。项目关联可选，项目概览的展示方式留待后续讨论。
