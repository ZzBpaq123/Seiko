# 账单导入与导出

在记账面板增加「导出账单」和「导入账单」。用户可以备份指定日期范围的收支，也可以批量导入历史记录。

## 导出账单

- 默认使用记账面板当前的日期范围，用户可以调整起止日期。导出包含起止日当天，以及该范围内的全部账单明细。
- 首版建议使用 UTF-8 CSV。导出字段包括账单日期、收支类型、金额、分类、支付方式和备注。日期使用 `YYYY-MM-DD`，金额以元为单位并保留两位小数，收支方向由类型表示。
- 导出的 CSV 可直接用于 Seiko Work 导入。中文、逗号和多行备注在导出与重新导入后应保持原值。

## 导入账单

1. 从记账面板上传 CSV。首版建议支持 Seiko Work 导出的文件，并提供相同格式的空模板供手工整理账单。
2. 预览识别结果，展示可导入行、格式错误和疑似重复。错误提示包含行号和字段。日期、收支类型和金额必填，并沿用现有账单的校验规则。
3. 用户确认选中的有效记录后写入。已确认导入的同一文件再次提交时，提示已导入。同日同金额的记录可以由用户判断是否保留两笔。
4. 导入完成后显示成功导入、跳过和失败的笔数，并刷新账单明细和统计。

## 实现范围

导出查询、导入预览和正式写入均以当前登录用户为范围。确认导入时由后端再次校验选中的记录，并处理重复提交。

微信、支付宝或银行卡原始账单的支持范围待定。确定来源后，可基于该来源的样例文件完善字段映射、交易状态和重复识别规则。
