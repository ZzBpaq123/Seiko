# 工作知识库

在 Seiko Work 增加独立的「知识库」，用来按天收集工作中值得留存的对话、截图、文件和链接。每条知识都有日期和标签，可以通过检索找回，也可以关联到项目。

## 资料收集

| 资料类型 | 首版建议的录入方式 |
| --- | --- |
| 对话 | 粘贴需要留存的聊天片段，可补充背景和原对话链接。 |
| 截图 | 粘贴或上传图片，可添加文字说明。 |
| 文件 | 上传原文件，可填写说明，之后可打开或下载。 |
| 链接 | 保存网址和标题，可补充用途或相关背景。 |

同一件事的多种资料可以归到一条知识。例如，一条「退款方案确认」可以包含聊天片段、一张截图和测试文档链接。进入知识库可以查看当天新增资料，也可以按资料日期回看历史。

## 知识条目信息

- **标题与说明**。记录这条资料讲了什么，方便定位。
- **资料日期**。默认今天，可以改为原对话或资料对应的日期。系统另记保存时间，方便找刚录入的历史资料。
- **标签**。一条知识可以有多个标签，例如「退款」「联调」。
- **项目与来源**。按需关联项目，记录原对话、文档或资料的网址。

## 检索

首版建议提供关键词搜索，覆盖标题、说明、粘贴的对话正文和标签。可以组合筛选日期范围、标签、项目和资料类型。搜索结果显示命中内容和资料日期，点开即可查看原条目及附件。

截图文字识别和 PDF 等文件正文索引的首版范围待定。后续可支持自然语言查找，结果附上来源条目和相关片段，方便核对。

## 与每日工作记录和项目的关系

- 每日工作记录可以引用已保存的知识条目。在周报或交接材料中也能带上相关资料链接。
- 项目概览可以直接列出关联知识。切换项目时，可以从同一个入口查看进展和资料。
- 知识条目、附件和检索结果按当前用户的资料归属控制访问。
