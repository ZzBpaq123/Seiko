# 邮件转待办

用户可以从邮件详情创建待办，之后在待办详情点击「查看原邮件」，回到对应的邮件继续处理。

## 创建待办

1. 在邮箱面板打开邮件详情，点击「创建待办」。
2. 用邮件主题预填任务标题。用户可以修改标题、补充任务说明并选择计划日期。
3. 保存后，任务出现在 `#tasks`。计划日期为今天或更早的未完成任务也出现在首页「今日待办」弹框，并触发待办亮点。

## 查看原邮件

- 由邮件创建的待办在详情中提供「查看原邮件」。点击后打开邮箱面板，并直接加载对应邮件的详情。邮件超出最近收件列表时，也可以按来源引用打开。
- 来源引用绑定创建任务时的邮箱账号和原邮件。更换邮箱账号后，先校验来源归属，再读取邮件详情。
- 原邮件已删除、来源邮箱已更换或暂时读取失败时，给出对应提示。用户仍能在 `#tasks` 查看、编辑和完成待办。

## 接口复用

创建和查询任务沿用现有任务接口，增加可选的原邮件来源引用。邮件正文通过现有详情流程按需加载，读取时校验当前用户及邮箱归属，并沿用现有邮件正文渲染处理。
