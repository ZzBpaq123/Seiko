# 首页日程与待办亮点

登录后，用户可以从首页分别查看今天的日程和需要处理的待办。首页提供两个独立的亮点，每个亮点打开自己的弹框。

## 首页展示规则

| 今天有日程 | 今天或逾期有未完成待办 | 首页展示 |
| --- | --- | --- |
| 有 | 有 | 日程亮点、待办亮点 |
| 有 | 无 | 日程亮点 |
| 无 | 有 | 待办亮点 |
| 无 | 无 | 首页保持原样 |

待办亮点只由计划日期为今天或早于今天的未完成任务触发。未来、未排期和已完成任务均从侧栏「待办」进入 `#tasks` 查看。登录后即可使用这个侧栏入口。

## 日程亮点

点击后打开「今日日程」弹框，展示今天的日程。第一版显示标题和时间，全天日程显示「全天」，跨天且与今天重叠的日程也纳入列表。

## 待办亮点

- 点击后打开「今日待办」弹框，展示今天要做的事和逾期事项。
- 支持在弹框里勾选完成。完成最后一项后，首页隐藏待办亮点，弹框保持打开，仍可快速新增或前往「全部待办」。
- 支持快速新增。首版建议只要求填写标题，计划日期默认今天。新增成功后立即刷新弹框和亮点。
- 点击「全部待办」进入 `#tasks`，可查看和管理未排期、未来和已完成事项。

## 接口复用

- 今日日程复用 `GET /api/events/range`，按当天的时间范围查询。
- 今日和逾期待办复用 `GET /api/tasks/today`。该接口已按计划日期筛选今天及更早的未完成任务。
- `#tasks` 复用现有任务列表及增改删接口，提供待办管理入口。
