# 日程到期提醒

用户可以给日程设置提醒，选择站内、邮件和微信服务号渠道。比如会议下午 3 点开始，选择提前 15 分钟，系统在 2:45 触发提醒。

## 日程设置

- 首版建议支持有明确开始时间的日程。创建或编辑时可关闭提醒，或选择开始时、提前 5 分钟、15 分钟、30 分钟。
- 首版建议启用提醒后默认选中站内渠道，邮件和微信服务号由用户按日程勾选。一个日程可以选多个渠道。
- 改期时更新待发送提醒。删除日程或关闭提醒时取消待发送提醒。

## 提醒渠道

| 渠道 | 用户体验 |
| --- | --- |
| 站内 | 在线时显示提示，点击查看日程。错过提示后，可在下次打开工作台时查看未读提醒。 |
| 邮件 | 后端在提醒时间通过现有 SMTP 配置向用户绑定的邮箱发送。邮件包含日程时间和查看入口。 |
| 微信服务号 | 用户在工作台绑定微信并启用该渠道后，后端在提醒时间通过服务号发送对应通知。通知字段和跳转能力以实际启用的模板为准。 |

## 微信服务号接入条件

- 开发前在微信公众平台确认目标服务号的通知接口权限、服务类目，以及是否有适用于日程提醒的模板。各服务号可用的类目和模板以公众号后台为准。 [腾讯云微信公众号接口文档](https://cloud.tencent.com/document/product/1301/100187)
- 建议在「提醒设置」中提供绑定入口。用户扫码进入微信授权流程，系统将该服务号下的微信用户标识 `OpenID` 与当前登录的工作台账号关联。用户可以在同一入口解除绑定。 [腾讯云公众号网页授权文档](https://cloud.tencent.com.cn/document/product/1301/101409)
- 微信提醒仅在完成绑定、用户启用该渠道并满足所用模板的关注或订阅要求时发送。可用的模板及发送条件需用目标服务号验证。

## 调度与发送

后端保存提醒时间并负责调度，关闭工作台页面后仍能触发邮件和微信渠道。按日程提醒和渠道记录发送状态，避免调度重复执行时重复发送。某一渠道失败时，其他已选渠道继续各自处理。
